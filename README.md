Конвертер видео в MP3 для Windows, macOS и Linux — в трёх лицах:
**портативное окно** (двойной клик, ничего устанавливать не нужно),
**командная строка** и **MCP-сервер для управления из ИИ-агентов**
(Claude и др.). ffmpeg программа ставит сама — одной кнопкой, в папку
рядом с собой, следов в системе не оставляет.

Что умеет:

- выравнивание громкости (EBU R128, двухпроходный loudnorm) — записи
  с разным звуком звучат одинаково;
- моно для речи и шумоподавление;
- разбивка на отдельные дорожки по паузам или фиксированным отрезкам;
- фрагменты (конвертировать с 1:30 до 2:05), выбор звуковой дорожки
  в multi-track видео, битрейт 96–320;
- встроенный предпросмотр видео: посмотреть запись и разметить
  начало/конец фрагмента прямо по кадрам (без звука; со звуком —
  кнопка «открыть в системном плеере»);
- живой прогресс: проценты внутри файла и оценка оставшегося времени.

Оформление — в фирменной теме «бумага и правка» дизайн-системы diff.legal:
бумажный фон, чернильные кнопки-пилюли, пара «−mp4 +mp3» и шрифты
Golos Text / JetBrains Mono (SIL OFL, лежат в `assets/fonts`).

## Самый простой способ (для новичков)

1. Скачайте/скопируйте папку целиком.
2. Откройте папку и **двойной клик по `START.bat`**.
3. В открывшемся окне: «Добавить видео…» → «Конвертировать». Готово.

При первом конвертировании конвертер сам скачает ffmpeg (~80 МБ, разово)
и дальше будет работать без интернета.

> Если Python не установлен, `START.bat` сам откроет страницу загрузки.
> В установщике Python отметьте галочку **«Add python.exe to PATH»**.

Вариант совсем без Python: запустите один раз `build_exe.bat` — получите
`dist\MP4-to-MP3.exe`, который работает на любом компьютере одиночным файлом.

## Графическое окно

```
python gui.py          # или: python main.py (без аргументов)
```

- добавление файлов или целой папки (с поиском в подпапках);
- выбор папки результата (по умолчанию mp3 ложится рядом с видео);
- качество 96–320 kbps;
- **фрагмент**: начало и конец (например `1:30` и `2:05`) — конвертируется кусок;
  кнопка «Смотреть / резать…» (или двойной клик по файлу в списке) открывает
  предпросмотр: проигрывание, перемотка по таймлинии и кнопки
  «Начало здесь» / «Конец здесь» для разметки фрагмента по кадрам;
- **разбивка на дорожки**: по паузам (концерты, миксы, подряд записанные песни —
  рез происходит по серединам пауз) или по времени (аудиокниги, лекции);
- **выравнивание громкости** — двухпроходный loudnorm по EBU R128 (−16 LUFS):
  сначала замер, потом линейная подстройка без компрессии артефактов;
- **моно** — для речи и подкастов, файл заметно меньше;
- **убрать шум** — срез гула снизу + FFT-шумодав, для речевых записей;
- тег title с именем файла — плееры показывают понятные названия;
- кнопка «Остановить» прерывает длинную партию;
- существующие mp3 не затираются — создаются копии «имя (1).mp3»
  (можно включить перезапись галочкой);
- в итоге — суммарный размер и время работы.

## Командная строка

```
python cli.py видео.mp4                        # один файл, mp3 рядом с ним
python cli.py папка_с_видео -o mp3 -b 320      # вся папка → папка mp3, 320 kbps
python cli.py . -r --overwrite skip            # рекурсивно, существующие пропустить
python cli.py песня.mp4 --start 0:35 --end 4:12   # только фрагмент
python cli.py концерт.mp4 --split-silence      # микс → отдельные дорожки по паузам
python cli.py концерт.mp4 --split-silence --silence-db -25   # аплодисменты = пауза
python cli.py аудиокнига.mp4 --split-every 10:00   # куски по 10 минут
python cli.py лекция.mkv --mono -b 96          # речь в моно, компактно
python cli.py интервью.mp4 --denoise --normalize   # почистить шум и выровнять звук
python cli.py видео.mkv --audio-stream 1       # вторая звуковая дорожка (нумерация с 0)
python cli.py разное/ --normalize              # выровнять громкость всей папки
python cli.py --setup-ffmpeg                   # только скачать/проверить ffmpeg
```

Все опции: `python cli.py --help`. Отмена длинной партии — `Ctrl+C`:
текущий файл прерывается, остальные помечаются «отменено».

Поддерживаемые контейнеры: `.mp4 .m4v .mov .mkv .avi .webm .ts .mts .m2ts .wmv .flv .3gp .ogv`

## Где конвертер хранит ffmpeg и настройки

Собранный exe **портативный**: ffmpeg, настройки и лог лежат рядом с
exe-файлом (`bin\`, `gui-settings.json`, `mp4tomp3.log`) — следов в
системе не остаётся, для полного удаления достаточно удалить папку.

| Что | Где (Windows) |
|---|---|
| Скачанный кнопкой ffmpeg | папка `bin\` рядом с exe (портативно) |
| Настройки окна и лог | рядом с exe |
| Запасное место (если рядом писать нельзя — Program Files и т.п.) | `%LOCALAPPDATA%\mp4-to-mp3-converter\` |
| ffmpeg из старых версий | `%LOCALAPPDATA%\mp4-to-mp3-converter\bin\` — находится и используется, настройки переносятся автоматически |
| Запуск из исходников | профиль пользователя, как раньше |

Переменная окружения `FFMPEG_PATH` указывает на конкретный ffmpeg.exe,
если нужно переопределить. ffmpeg не качается молча: при первом запуске
появляется кнопка **«Установить ffmpeg»**.

## Управление через ИИ-агента (MCP)

Встроен MCP-сервер (Model Context Protocol) — конвертером можно
управлять из любого агента, который умеет MCP (Claude Desktop,
Claude Code и др.).

```bash
pip install mcp                                   # одна зависимость сервера
python mcp_server.py                              # проверка руками (stdio)
```

Инструменты: `check_ffmpeg`, `install_ffmpeg`, `find_videos`,
`probe_media`, `convert` (фоновое задание), `job_status` (живой
прогресс и оценка остатка), `job_stop`, `jobs_list`.

Конфигурация Claude Desktop (Windows: `%APPDATA%\Claude\claude_desktop_config.json`).
Пример для репозитория в `C:\Tools\mp4-to-mp3-converter` — впишите свой
путь; в JSON каждый обратный слэш удваивается:

```json
{
  "mcpServers": {
    "mp4-to-mp3": {
      "command": "python",
      "args": ["C:\\Tools\\mp4-to-mp3-converter\\mcp_server.py"]
    }
  }
}
```

Требования к машине: `python` в PATH (проверьте в терминале `python
--version`) и пакет `mcp` (`pip install mcp`). Рабочая папка запуска не
важна — `mcp_server.py` сам находит каталог репозитория.

После установки пакета (`pip install ".[mcp]"`) доступна и команда
`mp4-to-mp3-mcp` — тогда в конфиге достаточно
`"command": "mp4-to-mp3-mcp"`, без пути к репозиторию.

Живые смоук-тесты клиент↔сервера по stdio:
`python scripts/mcp_smoke.py` (из папки репозитория) и
`python scripts/mcp_fresh_check.py <копия-репозитория>` (чистая копия,
чужая рабочая папка — условия запуска Claude Desktop).

## Разработка

```bash
pip install -r requirements-dev.txt
pytest                 # юнит-тесты + интеграционные (нужен ffmpeg, скачается сам)
```

Проверка на реальном видео (10 сценариев: конвертация, фрагмент,
нормализация, речевой режим, обе разбивки, ошибки, отмена):

```bash
python scripts/realdata_cycle.py путь/до/видео.mp4
```

Структура:

```
converter/
    util.py           # пути, битрейт, время (1:30 / 1:02:03), размеры — без ffmpeg
    ffmpeg_setup.py   # поиск/скачивание ffmpeg (портативно)
    core.py           # конвертация: convert_file / convert_batch, отмена, замер громкости
    splitting.py      # разбивка на дорожки: по паузам (silencedetect) и по интервалу
    jobs.py           # фоновые задания (мост между ядром и MCP)
    mcp_server.py     # MCP-сервер для ИИ-агентов (stdio)
    cli.py            # аргументы, отчёт
    gui.py            # окно на tkinter
    theme.py          # фирменная тема (токены, пилюли, шрифты)
gui.py, cli.py, main.py, mcp_server.py   # точки входа
tests/                    # pytest
scripts/                  # аудиты (макет, дизайн), MCP-смоук, цикл на реальном видео
START.bat                 # запуск для новичков (Windows)
start.sh / start.command  # то же для Linux / macOS
build_exe.bat             # сборка одиночного MP4-to-MP3.exe
```
